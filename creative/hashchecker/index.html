Hash Checker

简单、直观的文件哈希校验工具

软件简介

Hash Checker 是一款基于 Python / Tkinter 开发的 Windows 桌面小工具，用于快速计算和校验文件的哈希值，帮助你确认文件的完整性与真实性——无论是核对下载文件是否损坏，还是验证文件是否被篡改。

最新版本 v2.4.3_Build_20260824 作者 Liuzh Windows 桌面应用

主要功能

  • 纯绿色软件，即点即用，无需安装，无系统残留
  • 支持拖拽文件直接进行哈希计算
  • 后台异步扫描，大文件也不卡界面
  • 中英双语界面切换
