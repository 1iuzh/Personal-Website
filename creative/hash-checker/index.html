软件简介 // about

HashChecker.exe 是一款基于 Python / Tkinter 开发的 Windows 桌面小工具，用于快速计算和校验文件的哈希值，帮助你确认文件的完整性与真实性——适用于核对下载文件是否损坏，验证文件是否被篡改。

本软件适配 Windows 10 及更高版本系统。
目前已知 Windows 7 系统环境下存在兼容性故障，有空了再改~~

  • 纯绿色软件，即点即用，无需安装，无系统残留
